Простой FPS-шаблон на Unity с реализацией базовых механик: управление камерой от первого лица и стрельба с визуальной обратной связью.

##  Возможности

- **Mouselook** — плавное управление камерой от первого лица:
  - Регулируемая чувствительность мыши
  - Ограничение вертикального угла обзора (от -90° до 90°)
  - Инвертирование осей (опционально)
  - Блокировка / разблокировка курсора по нажатию Esc и клику ЛКМ

- **Стрельба**:
  - Прицел в центре экрана (визуальный маркер "*")
  - Raycast-выстрелы по нажатию левой кнопки мыши
  - Разрушаемые цели с анимацией падения и задержкой перед уничтожением

- **Визуальные эффекты**:
  - Сфера-индикатор на месте попадания (на 1 секунду)
  - Анимация опрокидывания цели (вращение на -75° по оси X) перед исчезновением

##  Технологии

- Unity (версия 6000.4.2f1)
- C#
- Встроенный физический движок Unity (Raycast)
- Компоненты: Camera, Transform, Collider

##  Структура скриптов

| Скрипт | Назначение |
|--------|------------|
| `MouseLook.cs` | Управление поворотом камеры и игрока от мыши |
| `RayShooter.cs` | Обработка выстрелов, Raycast, визуальная обратная связь |
| `ReactiveTarget.cs` | Поведение цели при попадании (анимация смерти) |

##  Настройка сцены

1. **Игрок (Player)**
   - Создайте пустой GameObject → назовите "Player"
   - Добавьте компонент `CharacterController` (опционально)
   - Добавьте скрипт `MouseLook.cs`
   - В поле `playerBody` перетащите самого себя (родительский объект)

2. **Камера**
   - Переместите MainCamera внутрь объекта Player
   - Установите позицию камеры относительно Player (например, Y = 0.5..1.64)
   - Добавьте к камере скрипт `RayShooter.cs`

3. **Цели**
   - Создайте GameObject (например, куб или сфера) с коллайдером (`BoxCollider` или `SphereCollider`)
   - Добавьте скрипт `ReactiveTarget.cs`
   - (Опционально) Добавьте Rigidbody, если нужна физика

4. **Окружение**
   - Добавьте стены, пол и другие препятствия с коллайдерами для работы Raycast'а

##  Управление

| Действие | Клавиша |
|----------|---------|
| Выстрел | Левая кнопка мыши |
| Заблокировать курсор | ЛКМ (при разблокированном курсоре) |
| Разблокировать курсор | Esc |

##  Установка

1. Клонируйте репозиторий
2. Откройте проект в Unity Hub
3. Откройте сцену `SampleScene` (или создайте свою по инструкции выше)
4. Нажмите Play

##  Настройка параметров

### MouseLook.cs
- `mouseSensitivity` — чувствительность мыши
- `minVerticalAngle` / `maxVerticalAngle` — ограничение взгляда вверх/вниз
- `invertVertical` / `invertHorizontal` — инвертирование осей

### RayShooter.cs
- Время жизни индикатора попадания регулируется в `WaitForSeconds(1)`

### ReactiveTarget.cs
- Время задержки перед уничтожением регулируется в `WaitForSeconds(1.5f)`
- Угол падения цели регулируется в `Rotate(-75, 0, 0)`
